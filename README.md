# Pharma Discount Monitor
## نظام مراقبة الأسعار وانعكاس الخصومات لدى المذاخر

تطبيق ويب يعمل محلياً داخل المتصفح. يتابع أسعار بيع المذاخر للصيدليات، ويحسب مقدار ما عكسه كل مذخر من خصم الشركة، وما بقي له منه.

> **القاعدة الجوهرية (نقاط مئوية من السعر الأصلي):**
> خصم الشركة − الخصم الذي عكسه المذخر للصيدلية = الخصم المتبقي للمذخر
>
> مثال: 10,000 دينار، خصم 21%، بيع بـ 8,900 ← معكوس **11%**، متبقٍ **10%** (وليس 52.38%).

---

## التشغيل

المتطلبات: Node.js 18 أو أحدث.

```bash
cd pharma-discount-monitor
```

```bash
npm install
```

```bash
npm run dev
```

ثم افتح الرابط الذي يظهر في الطرفية (عادةً `http://localhost:5173`).

| الأمر | الوظيفة |
|---|---|
| `npm run dev` | خادم التطوير (متاح أيضاً على الشبكة المحلية لفتحه من الهاتف) |
| `npm test` | تشغيل اختبارات الحسابات وقاعدة البيانات (35 اختباراً) |
| `npm run build` | بناء نسخة إنتاجية في مجلد `dist/` |
| `npm run preview` | معاينة النسخة المبنية |

مجلد `dist/` ملفات ثابتة بالكامل، ويمكن رفعه على أي استضافة ثابتة أو مشاركة ملفاته مباشرة، إذ يستخدم مسارات نسبية وتوجيهاً بعلامة `#`.

**أول تشغيل:** من لوحة التحكم اضغط «تحميل بيانات تجريبية» للتجربة، أو ابدأ مباشرة بإدخال بياناتك.

## التقنيات المستخدمة ولماذا

| التقنية | سبب الاختيار |
|---|---|
| **Vue 3** + Vite | خفيف وسريع، ومكوّنات منظمة يسهل توسيعها |
| **Tailwind CSS** | تصميم RTL متجاوب ومتسق دون ملفات CSS ضخمة |
| **IndexedDB عبر Dexie** | تخزين كميات كبيرة من البيانات، مع معاملات (transactions) وفهارس واستعلامات حية تحدّث الواجهة تلقائياً |
| **Chart.js** | مخططات تفاعلية مع تلميحات (tooltips) تدعم RTL |
| **SheetJS (xlsx)** | قراءة ملفات xlsx/xls/csv وكتابتها |
| **Vitest** + fake-indexeddb | اختبار الحسابات وطبقة البيانات خارج المتصفح |

لم يُستخدم LocalStorage لتخزين البيانات. يطلب التطبيق من المتصفح تخزيناً دائماً (`navigator.storage.persist`).

## المعادلات (`src/lib/calc.js`)

| الرمز | المعادلة |
|---|---|
| B | سعر شراء المذخر = الأصلي × (1 − خصم الشركة / 100) |
| C | الخصم المعكوس % = (الأصلي − سعر البيع) / الأصلي × 100 |
| D | الخصم المتبقي % = خصم الشركة − الخصم المعكوس |
| E | الخصم المعكوس بالدينار = الأصلي − سعر البيع |
| F | الخصم المتبقي بالدينار = الأصلي × خصم الشركة / 100 − الخصم المعكوس بالدينار |
| G | سعر البيع المرجعي = الأصلي × (1 − خصم الشركة / 100) |

- تُقرَّب النسب داخلياً إلى 4 منازل عشرية، والمبالغ إلى منزلتين، وذلك لإزالة أخطاء الفاصلة العائمة (مثلاً 11.000000000000002 تصبح 11).
- إذا كان المتبقي سالباً يظهر تنبيه: «الخصم المعكوس أكبر من خصم الشركة بمقدار X نقطة مئوية»، دون أي حكم على المذخر.
- يقبل التطبيق الأرقام العربية-الهندية (١٠٬٠٠٠) والفواصل في الإدخال.

### الاختبارات (`tests/`)

- `calc.test.js`: المثال الأساسي (الجدول الكامل)، والحالات الخمس في القسم 19، والدقة، والتحقق من المدخلات، وأولوية الخصومات، والمؤشرات الذكية.
- `repo.test.js`: حفظ الاسم كما أُدخل، ومنع التكرار، والسجل التاريخي وفرق السعر، وثبات اللقطات التاريخية بعد تعديل القائمة، وعدم تغيّر القوائم القديمة، وفصل البيانات التجريبية.

يتحقق التطبيق من الحالات نفسها أيضاً داخل صفحة **حاسبة الخصم**.

## بنية قاعدة البيانات (`src/db/index.js`)

```
products ──┐
           ├──< batchProducts >── priceBatches ──< distributorDiscounts >── distributors
           │                          │                                        │
           └───────────< priceMonitoring (لقطة: السعر الأصلي + خصم الشركة) >──────┘
                                  │
                                  └──< priceHistory (سجل تدقيق: إنشاء/تعديل/حذف)
settings (مفتاح/قيمة)
```

| الجدول | الوصف |
|---|---|
| `products` | الأدوية: الاسم (يُحفظ حرفياً)، الاسم العلمي، الشركة المصنعة، **نوع العلاج** (شراب، حبوب، كريم، مرهم، معلق، معقم، قطرة)، **التغليف** (مغلف / بدون غلاف)، العبوة، السعر الأصلي الحالي، المجموعة، الحالة |
| `distributors` | المذاخر: الاسم، المحافظة، المنطقة، المدينة، المسؤول، الهاتف، معلومات الاتصال |
| `priceBatches` | قائمة أسعار أو طلبية كإصدار مستقل: رقم، اسم، تاريخ، معمل، نوع، مذخر (للطلبية) |
| `batchProducts` | سعر كل منتج وخصم الشركة له داخل قائمة معيّنة (فريد على `[batchId+productId]`) |
| `distributorDiscounts` | خصم خاص بمذخر داخل قائمة: لمنتج محدد، أو لكامل القائمة عندما `productId = 0` |
| `priceMonitoring` | كل سعر بيع مسجّل، مع **لقطة** من السعر الأصلي والخصم الفعّال، والسعر السابق والفرق، والمصدر، والمستخدم |
| `priceHistory` | سجل تدقيق لكل إنشاء أو تعديل أو حذف، مع القيم القديمة والجديدة |
| `settings` | المستخدم، العملة، المنازل العشرية، فئات المؤشرات، العتبات، آخر نسخة احتياطية |

**مفتاح المنتج:** الاسم + نوع العلاج + حجم العبوة + التغليف، فـ«بتنوسام كريم» و«بتنوسام مرهم» منتجان مختلفان.

**التغليف:** المنتج نفسه مغلفاً وبدون غلاف يُسجَّل كمنتجين منفصلين لكل منهما سعره، ويُعرض الاسم مع التغليف للتمييز، مثل «بارا 500 (بدون غلاف)». جداول قوائم الأسعار مقسّمة إلى مجموعات حسب نوع العلاج ثم التغليف، مع فلاتر سريعة وتطبيق خصم على مجموعة كاملة.

**أولوية خصم الشركة:** خصم المذخر للمنتج ← خصم المذخر للقائمة ← خصم القائمة للمنتج.

**سلامة البيانات:**
- لا يُحذف أي سعر سابق. كل متابعة سجل جديد.
- تعديل قائمة أسعار لاحقاً لا يغيّر حسابات المتابعات السابقة، لأن كل متابعة تحفظ لقطتها الخاصة.
- لا يمكن حذف منتج أو مذخر أو قائمة إذا ارتبطت بها متابعات تاريخية.
- يُمنع تلقائياً تكرار المنتجات والمذاخر والمتابعات، مع إمكانية التجاوز بعد تأكيد صريح.
- تُرفض الأسعار السالبة أو الصفرية، وأي خصم خارج المدى من 0 إلى أقل من 100.
- البيانات التجريبية معلَّمة `isDemo = 1`، ويمكن إخفاؤها أو حذفها دون المساس ببياناتك.

## الصفحات

| الصفحة | الوظيفة |
|---|---|
| لوحة التحكم | 10 بطاقات مؤشرات، و5 مخططات، وأحدث المتابعات، وتنبيهات التحقق، والمنتجات ذات الفروقات الكبيرة |
| متابعة الأسعار | إدخال ميداني سريع (مذخر ← قائمة ← منتج ← سعر) مع تحليل فوري وعرض السعر السابق، وسجل قابل للفلترة والتعديل مع سجل تدقيق |
| الأدوية | إضافة وتعديل وحذف وبحث وفرز وفلاتر، واستيراد وتصدير Excel |
| تحليل المنتج | بطاقة المنتج، وتحليل الخصم في السوق، ومقارنة المذاخر بخمسة أنماط ترتيب، ومخططات |
| المذاخر وتفاصيل المذخر | بيانات المذخر، ومتوسطات الانعكاس، وأحدث الأسعار، والتطور التاريخي، وتصدير أسعاره |
| قوائم الأسعار | إنشاء قائمة يدوياً أو بنسخ قائمة سابقة، وخصومات خاصة بالمذاخر، وتعديل مع تحذير، وتصدير وطباعة |
| المقارنة السوقية | منتج + فترة + اختيار مذاخر، مع ترتيب ومخططات ومقارنة تاريخية حسب القائمة، وطباعة وتصدير |
| السجل التاريخي | تطور السعر أو المعكوس أو المتبقي لكل منتج لدى كل مذخر، مع سجل التعديلات |
| التقارير | تقرير الخصم المعكوس، وتقرير الخصم المتبقي، وتنبيهات التحقق، وجميع عمليات التصدير |
| استيراد Excel | ثلاثة أنواع: **قائمة أسعار الشركة** (السعر الأصلي + خصم الشركة، تُنشئ قائمة جديدة)، **أسعار بيع مذخر للصيدليات** (تُسجَّل كمتابعات مقارنةً بقائمة الشركة)، و**منتجات فقط**. مع معاينة ومطابقة أعمدة واكتشاف المكرر والأخطاء والتنبيهات قبل التأكيد |
| حاسبة الخصم | حساب سريع، والمثال الاختباري، والتحقق الحي من اختبارات القسم 19 |
| الإعدادات | المستخدم والعملة والمنازل العشرية، وفئات المؤشرات القابلة للتعديل، والعتبات، والنسخ الاحتياطي والاستعادة، والبيانات التجريبية |

**الطباعة / PDF:** زر «طباعة» في صفحات التحليل يخفي القوائم والأزرار ويضيف ترويسة للتقرير. اختر «حفظ كـ PDF» من نافذة الطباعة في المتصفح.

## النسخ الاحتياطي

البيانات محفوظة في متصفح هذا الجهاز فقط. لحمايتها:
1. من **الإعدادات** اضغط «تنزيل نسخة احتياطية JSON» بانتظام. يذكّرك التطبيق بذلك إذا مرّ أكثر من 7 أيام.
2. للاستعادة اختر ملف JSON. ينزّل التطبيق تلقائياً نسخة أمان من بياناتك الحالية قبل استبدالها.
3. لنقل البيانات إلى جهاز آخر: نزّل نسخة احتياطية من الجهاز الأول، ثم استعدها على الجهاز الثاني.

> تنبيه: مسح بيانات المتصفح (Site data) لهذا الموقع يحذف قاعدة البيانات، فاحتفظ بنسخ احتياطية دائماً.
